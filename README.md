# Armor-and-item-HUD-plus

Armor & item HUD + - free Minecraft Bedrock addon by TamilCrafters Studio. Armor durability HUD, item counters, effect timers and held-food hunger preview. This repo holds the readable source of v1.1.24 so anyone can see how the addon is built.
